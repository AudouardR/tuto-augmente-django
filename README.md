# Application Django

Il s'agit d'une application de gestion de sondages. À la page d'accueil, on peut voir les 5 derniers sondages. On peut créer des sondages (avec la question et jusqu'à 5 propositions), ou sélectionner une question dans la liste, répondre au sondage puis voir les résultats.

## Lancer l'application

Pour lancer l'application, il faut :
* Ouvrir un terminal PowerShell à la racine du projet
* Exécuter la commande suivante : >>> python manage.py runserver (ou py manage.py runserver)
* Pour ouvrir le site, sur un navigateur web, ouvrir le lien suivant : http://127.0.0.1:8000/polls/all
